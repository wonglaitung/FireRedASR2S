# 自發粤英验证集（153 条）

- 来源：HuggingFace [`ASLP-lab/WSYue-ASR-eval`](https://huggingface.co/datasets/ASLP-lab/WSYue-ASR-eval) 的 Short 子集
- 授权：**CC BY-NC 4.0**（仅限非商业用途；商用需另行确认）
- 内容：从 Short 子集中筛出含英文词的 153 条，覆盖访谈/旁白/日常等场景
- 格式：16kHz / 16bit / mono WAV，共约 971.76s
- 用途：真实自發/多领域粤英混说压力测试，不参与 LM 训练

> 这是第三方 benchmark 的子集，不是官方完整 WSYue-eval 结果；引用请同时引用 WSYue 论文/数据集。
