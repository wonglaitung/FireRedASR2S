# 个人听写公开代理集（100 条）

> 版本：v1.0
> 用途：个人语言输入/听写的**公开代理集**，不是真实用户听写数据。

- 来源：HuggingFace [`Shelton1013/SwitchLingua_audio`](https://huggingface.co/datasets/Shelton1013/SwitchLingua_audio) 的 `Cantonese/` 子集
- 授权：**CC BY-NC 4.0**，仅非商业用途
- 选取：`single_turn`、含英文词、按 topic 分层抽 100 条
- 格式：16kHz / 16bit / mono WAV，共约 529.23s
- 主题：50 个日常/工作主题，覆盖旅游、科技、购物、健康、音乐等
- 转写：保留英文拉丁；不做说话人区分

> SwitchLingua 是生成/录制的混说数据，偏朗读，不是真实听写。真实个人听写仍需按 `docs/DATA.md` 自录。
