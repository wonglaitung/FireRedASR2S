# 纯粤语验证集（20 条）

- 来源：HuggingFace [`AlienKevin/wordshk_cantonese_speech`](https://huggingface.co/datasets/AlienKevin/wordshk_cantonese_speech)
- 授权：**CC BY 4.0**（使用时请保留署名与来源）
- 内容：words.hk 词典例句/短句，纯粤语，无英文
- 20 条，约 81.64s，16kHz/16bit/mono WAV
- 基线：AED CER **11.5%**

用途：检查 AED 的粤语 CER 是否因英文优化而退化。

> 这些是词典例句/朗读句，不是自發對話；部分句子偏书面或释义。
