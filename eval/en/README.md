# 纯英文验证集（20 条）

- 来源：HuggingFace [`openslr/librispeech_asr`](https://huggingface.co/datasets/openslr/librispeech_asr)，`validation.clean`
- 授权：**CC BY 4.0**
- 内容：英文朗读，7 位说话人，20 条，约 153.94s
- 格式：16kHz/16bit/mono WAV
- 基线：AED WER **1.1%**

用途：检查 AED 的英文 WER 是否因粤语/混说优化而退化。

> 这是 native English，不是香港口音英文；不能单独代表港式英文。
